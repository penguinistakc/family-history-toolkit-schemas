# Family History Toolkit Schema Repository

- The repository publishes versioned JSON Schemas for the research-repository contract.
- The canonical schema identities use <https://schemas.kcopensource.org/>....
- Released schema versions are immutable.
- Materialized repositories validate against pinned local copies, not network downloads.
- Hosted schemas support inspection, interoperability, and explicit update discovery.
- A checksum or identity mismatch must be treated as an error.
